## 🛠 Скрипты (4 файла)

### scripts/deploy.js
**Основной скрипт деплоя**
- Деплоит все 5 контрактов
- Связывает их между собой
- Сохраняет адреса
- Команда: `npm run deploy:sepolia`

### scripts/check-balance.js
**Проверка баланса**
- Показывает текущий баланс
- Предупреждает если мало ETH
- Команда: `npm run check-balance`

### scripts/verify-deployment.js
**Проверка деплоя**
- Проверяет связи контрактов
- Выводит ссылки на Etherscan
- Команда: `npm run verify-deployment`

### scripts/generate-verification-commands.js
**Генерация команд верификации**
- Создает готовые команды
- Сохраняет в verify-commands.sh
- Команда: `node scripts/generate-verification-commands.js`
